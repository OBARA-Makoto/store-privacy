プライバシーポリシー

CursorBeacon（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の保護に努めます。

本ポリシーの正本は英語版です。この日本語版は、その訳です。

1. 個人情報の収集

本アプリは、利用者を識別するための個人情報を、開発者が収集することはありません。

本アプリでは、アカウント登録や氏名・住所・電話番号・メールアドレス等の個人情報の入力を求めることはありません。

2. データの取り扱い

設定情報（エフェクト、色、感度、ホットキー、言語など）は、利用者のコンピューター上の次の場所に保存されます。

%AppData%\Roaming\mobara\CursorBeacon\config.ini

「Windows 起動時に開始」を有効にした場合、Windows のスタートアップにショートカットが作成されます。

試用期間の判定のため、初回起動日を、その Windows ユーザーのレジストリに端末内のみ保存します。この記録が端末の外へ送られることはありません。

設定ファイルで有効にした場合に限り、性能調査用のログ（ProfileTiming.log）が同じフォルダに端末内のみ保存されます。既定では有効になりません。

上記のデータが、本アプリから開発者または第三者のサーバーへ送信されることはありません（次項の Microsoft Store による購入・ライセンス確認を除きます）。

3. マウス・キーボード入力

本アプリは、カーソル位置の視覚的な表示と、マウスの素早い動き（シェイク）の検出のために、OS から入力イベントを受け取ります。

入力した文字、パスワード、IME の変換文、クリップボード、画面の内容を記録したり、開発者や第三者へ送信したりすることはありません。

端末上での処理の概要は次のとおりです。

- 画面上のカーソル座標の取得、および利用者が選んだ「キーでマウスを呼び戻す」によるカーソル移動（GetCursorPos / SetCursorPos）

- バックグラウンドでもマウス移動を検知し、シェイク判定とエフェクト表示を行う（Raw Input）

- 利用者が設定したショートカットによるマウスの呼び戻し（RegisterHotKey。既定は Ctrl + Alt + Space）

- 修飾キーやマウスボタンが押されているかの参照（GetAsyncKeyState）。ドラッグ中などの誤判定を防ぐためと、設定画面でショートカットを割り当てているあいだに押したキーを読み取るために使います。保存するのは選んだショートカットだけで、上記の設定ファイルに残します。それ以外のキー入力の記録は残しません。

- 一部の全画面オーバーレイを、キー操作やマウス操作で閉じる。キーボードの Raw Input はこの目的と入力状態の判定に用い、キーの内容は保存しません。

カーソル拡大のエフェクトでは、システム標準の矢印カーソルを端末内で読み取り、大きく描くことがあります。そのあいだは、システムの矢印を一時的に非表示のカーソルへ差し替え、エフェクトが終わると元に戻します。その画像や差し替えをファイルとして保存したり、端末の外へ送ったりすることはありません。

低レベルキーボード／マウスフック（WH_KEYBOARD_LL / WH_MOUSE_LL）、キーロガー、IME 連携による文字の取得は行いません。

4. 外部サービス

本アプリの中心機能はオフラインで動作します。利用者の個人情報を収集する目的で、独自の解析サービスや広告サービスを利用していません。

利用者が選んだ場合に限り、次が起動します。

- Microsoft Store によるフル機能の購入。決済とライセンスは Microsoft のサービスおよび Microsoft のプライバシーポリシーに従います。開発者がクレジットカード番号等の決済情報を直接取得・保存することはありません。

- About またはメニューから、システムのブラウザで Microsoft Store の製品ページ、または公開元の公開ページを開く。

5. 第三者への提供

本アプリが取得した利用者の情報を、開発者が第三者に提供、販売、共有することはありません。

ただし、Microsoft Store 上の購入・ライセンス処理に伴い、Microsoft が所定の情報を取り扱う場合があります。詳細は Microsoft のプライバシーポリシーをご確認ください。

6. プライバシーポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、変更後の内容を本アプリまたは本アプリの公開ページ等で確認できるようにします。
