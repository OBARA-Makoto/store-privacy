プライバシーポリシー

Vireluno（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の保護に努めます。

本アプリは、画面のキャプチャと、画像への注釈・簡易編集を行う Windows 向けアプリです（VirelunoCapture および VirelunoEditor）。

1. 個人情報の収集

本アプリは、利用者を識別するための個人情報を、開発者が収集することはありません。

本アプリでは、アカウント登録や氏名・住所・電話番号・メールアドレス等の個人情報の入力を求めることはありません。

2. データの取り扱い（端末内）

キャプチャした画面、編集中の画像、文字認識（OCR）で読み取った文字、設定、最近開いたファイルの場所、前回入力した注釈の文面は、利用者のコンピューター上のファイルまたは一時ファイルとして扱います。設定は、利用者のアプリデータフォルダに保存します。

画面の撮影、文字認識（Windows 標準の OCR、または利用者が別途インストールした Tesseract）、注釈の編集は、いずれも端末上で行います。画像や読み取った文字を、本アプリから開発者または第三者のサーバーへ送信することはありません。

キーボードショートカットは、キャプチャを開始するために OS へ登録する範囲で使います。入力内容を記録（いわゆるキーログ）したり、開発者や第三者へ送信したりすることはありません。

利用者がコピーした画像や文字は、Windows のクリップボードに置かれます。保存したファイルは、利用者が指定した場所に残ります。

3. 利用者が選んだときの共有

利用者が「共有」を実行したときだけ、Windows の共有画面を開き、選んだ共有先へ画像を渡します。渡した画像の取り扱いは、その共有先のサービスに従います。開発者がその画像を受け取ることはありません。

About などのリンクを開いたときは、利用者のブラウザーで公開ページを表示します。本アプリがその操作に利用者の個人情報を添付して送ることはありません。

4. 外部サービス（Microsoft Store）

本アプリは、利用者の個人情報を収集する目的で、独自の解析サービスや広告サービスを利用していません。

本アプリを Microsoft Store から入手した場合、入手・更新、および提供される場合のアプリ内購入やライセンスの確認は、Microsoft Store を通じて行われます。決済情報の取り扱い、アカウント情報、購入履歴等は Microsoft のサービスおよび Microsoft のプライバシーポリシーに従います。本アプリの開発者が、クレジットカード番号等の決済情報を直接取得・保存することはありません。

5. 第三者への提供

本アプリが取得した利用者の情報を、開発者が第三者に提供、販売、共有することはありません。

ただし、前項の Microsoft Store 上の処理、および利用者が自ら選んだ共有先へ画像を渡す場合は除きます。共有先や Microsoft が所定の情報を取り扱うときは、各提供者のプライバシーポリシーをご確認ください。

6. プライバシーポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、変更後の内容を本アプリまたは本アプリの公開ページ等で確認できるようにします。

7. お問い合わせ

本ポリシーに関するお問い合わせは、アプリの公開元（studiomobara@gmail.com）までご連絡ください。
